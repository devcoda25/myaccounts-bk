## 2024-05-18 - Missing Composite Indexes on High-Volume Models
**Learning:** High-volume user activity and parental models like `ParentalApproval`, `ParentalActivity`, `Notification`, `SecurityReport`, `SupportTicket`, `Session`, `AuditLog`, and `ChildProfile` were missing critical composite indexes (e.g., `@@index([userId, createdAt])`) needed to efficiently execute their `findMany` queries with sorting. This forces the database to perform expensive in-memory sorts during chronologically ordered pagination.
**Action:** Add targeted composite indexes to Prisma models specifically matching the query patterns (filtering key + sorting key) used in the corresponding repository layer (e.g., `[userId, createdAt]` or `[childId, at]`). Ensure a comment is provided above each index to document its performance optimization.
